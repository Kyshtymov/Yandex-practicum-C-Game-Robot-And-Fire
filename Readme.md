# 🤖 Robot Rescue

2D-игра на **Qt / C++**, в которой робот спасает людей из горящего здания. Проект демонстрирует работу с Qt Widgets, изометрическую отрисовку, игровой цикл, систему анимаций, ИИ персонажей и загрузку уровней из JSON.

---

## 📋 Описание

Игрок управляет роботом, который перемещается по этажам здания с видом сверху в изометрии. На пути встречаются стены, двери, лестницы и жертвы пожара. Жертвы ведут себя по собственному алгоритму: пока не встретили робота — блуждают хаотично, а после встречи начинают следовать за ним. Освещение вокруг робота имитируется через затемнение сцены — чем дальше от источника света, тем темнее.

Проект создавался как полноценная игра с расширяемой архитектурой: уровни описываются в JSON, объекты загружаются через фабрику загрузчиков, а игровой цикл построен на собственной системе таймеров и анимаций.

---

## ✨ Возможности

- 🎮 **Управление роботом** — стрелки клавиатуры для перемещения
- 🏢 **Многоэтажные уровни** — переход между этажами через лестницы
- 🚪 **Интерактивные объекты** — двери, которые открываются и закрываются
- 👥 **ИИ жертв** — две фазы поведения: хаотичное блуждание и следование за роботом
- 🔦 **Динамическое освещение** — эффект фонарика с затемнением сцены
- 🎨 **Изометрическая отрисовка** — псевдо-3D проекция игрового поля
- 🎞️ **Анимации** — плавное перемещение персонажей, смена спрайтов по направлению
- 📥 **Загрузка уровней из JSON** — описание этажей, стен, объектов и персонажей
- 🧩 **Расширяемая фабрика загрузчиков** — легко добавить новые типы объектов
- 🔄 **Собственная система таймеров** — отложенные колбэки и планирование событий

## 🚀 Сборка и запуск

### Требования

- **Qt 5.15+** или **Qt 6.x**

### Запуск

Игра запускается как обычное Qt-приложение. Управление — стрелками клавиатуры.

---

## 🎮 Управление

| Клавиша | Действие |
|---|---|
| ↑ | Движение вверх |
| ↓ | Движение вниз |
| ← | Движение влево |
| → | Движение вправо |

Робот сначала поворачивается в нужную сторону, а затем начинает движение. Повторное нажатие в ту же сторону продолжает движение без остановки.

## 🏗️ Архитектура

Проект построен на нескольких ключевых абстракциях:

```
┌────────────────┐
│   MainWindow   │  ← Qt-окно, клавиатура, paintEvent
└───────┬────────┘
        │ содержит
        ▼
┌────────────────┐        ┌────────────────┐
│   Controller   │───────►│      Game      │
│  (ввод, тик)   │        │  (мир, кадр)   │
└────────────────┘        └───────┬────────┘
                                  │ содержит
                                  ▼
                    ┌──────────────────────────┐
                    │       GameContext        │
                    │ object_map, field,       │
                    │ random, assets, timer    │
                    └──────────────────────────┘
                                  │
        ┌─────────────────────────┼─────────────────────────┐
        ▼                         ▼                         ▼
┌──────────────┐         ┌──────────────┐         ┌──────────────┐
│   Object     │         │   Field      │         │  Painter     │
├──────────────┤         ├──────────────┤         ├──────────────┤
│ Character    │         │ Floor        │         │ изометрия,   │
│ Stairs       │         │ Tile, Wall   │         │ затемнение   │
│ Player       │         │ Door         │         │              │
│ Victim       │         │              │         │              │
└──────────────┘         └──────────────┘         └──────────────┘
```

### Ключевые решения

- **`GameContext`** — единый контекст, доступный всем объектам. Содержит ссылки на карту объектов, поле, генератор случайных чисел, загрузчик ассетов и таймер. Позволяет объектам взаимодействовать друг с другом без прямых зависимостей.
- **Паттерн «Стратегия» для загрузчиков** — `Loader<T>` хранит словарь функций-загрузчиков по имени типа. Регистрация новых типов происходит через статические объекты (`GrassLoader`, `DoorLoader` и т.д.). Это позволяет добавлять новые объекты без изменения кода загрузчика.
- **Изометрическая проекция** — `Painter` переводит трёхмерные координаты клетки в экранные через матрицу преобразования. Это создаёт ощущение объёма без использования 3D-графики.
- **Собственная система таймеров** — `Timer` хранит отложенные колбэки и вызывает их при `UpdateTime`. Это позволяет строить анимации и цепочки действий без Qt-таймеров.
- **Анимация через `Transition`** — плавное перемещение персонажа между клетками интерполируется по времени. По завершении вызывается callback, который запускает следующий шаг.
- **ИИ жертвы** — конечный автомат с двумя состояниями: `BROWNIAN` (хаотичное блуждание) и `FOLLOW` (следование за роботом). Переход между состояниями происходит по расстоянию до игрока.
- **Освещение** — `FlashlightDarkener` вычисляет затемнение каждой точки сцены в зависимости от направления взгляда робота. `RadialDarkener` даёт круговое затемнение.

## 🗺️ Формат уровня

Уровни описываются в JSON. Пример структуры:

```json
{
  "size": { "w": 10, "h": 10 },
  "player": { "pos": [0, 0], "dir": "r" },
  "floors": [
    {
      "regions": [
        { "pos": [0, 0], "size": [10, 10], "tile": "marble-black" }
      ],
      "walls": [
        { "pos": [0, 0], "dir": "l", "wall": "edge" }
      ],
      "objects": [
        { "type": "victim", "pos": [3, 3], "dir": "d" },
        { "type": "stair", "pos": [5, 5], "dir": "u", "down": false }
      ]
    }
  ]
}
```

Загрузка происходит через `LevelLoader::LoadFromFile`. Регионы задают тайлы пола и стены по периметру, `walls` — отдельные стены, `objects` — персонажей и интерактивные элементы.
